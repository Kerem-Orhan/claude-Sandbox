# Steps left for the user (about 30 min; none done by the team)
1. Open product/budget-planner.html in Chrome, Print (Ctrl+P), Destination: Save as PDF, Paper Letter, Margins Default, enable Background graphics. Save as Monthly-Budget-Planner.pdf. Check it is 9 pages (cover plus 8).
2. Open product/cover.svg in Chrome, take a screenshot or export to PNG (or use any SVG-to-PNG site) for the listing image. Screenshot 1-2 PDF pages as extra images.
3. Create a free Gumroad (or Etsy/Ko-fi) account, create a product, upload the PDF, paste title, description, tags from listing.md, set price $10, publish.
4. Share the product link yourself (friends, social media) honestly. Note: platform fees are about 10% (Gumroad) so $10 sale nets about $9; expect to need 1-2 sales. No sales are guaranteed.
